# Spaceman 0.1.3

- Releases the tile of an app that closes its only window by hiding it, so the other tiles fill the
  space within 2 seconds instead of leaving an empty column.
- Minimizing an app's only window, or hiding the app with Cmd-H, now also releases its tile after
  2 seconds. The window comes back as a new tile.
- Remembers window placements across restarts.
- Improves window classification, new-window adoption, and switching resilience.
- Records windows that refuse a smaller size as constrained instead of misplaced.
- Drains Objective-C autorelease pools on background queries.
- Updates the bundled TLS libraries to distrust the compromised eMudhra certificate authorities.
- Records recent input timing in focus-follow log lines so unexpected workspace switches can be
  diagnosed, without recording which keys were pressed.
