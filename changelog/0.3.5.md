## Major
- Rebuilt the setup tour as four short steps. `Your workspaces` shows the windows you have open as miniature workspaces, with each app's icon where it would tile: browsers on 1, editors and terminals on 2, chat and mail on 3, documents on 4, media on 5, never more than two tiles on a laptop display. Click or drag an icon to move it, then `Arrange & start`.
- Tiling now starts only when you press `Arrange & start`. `Skip` leaves every window where it is, and `Undo & restore` on the last step puts them all back.

## Improvements
- The arrangement moves the windows that are open and saves no app-to-workspace rule, so a browser's or terminal's next window opens where you are. The only rules it writes are `float` rules for small utilities.
- Calculator, Stickies, System Settings, Digital Color Meter, 1Password and Hex start floating instead of taking half a display.
- Settings opens on General. Rules now says what it is: `Where new windows open`, optional, and any window can still move to any workspace.
- An app can have more than one rule. `+` lists every running app, and one that already has a rule asks for a `Title contains` filter, so Safari's Work windows can open on workspace 1 and its Claude windows on workspace 2. Right-click a rule to change its filter.
- Settings › Rules shows the apps Spaceman floats by default under `Floating by default`. Click one to tile it or pin it on all workspaces.
- The Workspace HUD's right-click menu says what each item does: `Always open Safari on Workspace 2` for where new windows open, `Pin Safari on all workspaces` for a float that shows everywhere, and `Tile` for an app that floats by default.
- A `route` rule for an app that floats by default, such as Stickies, now keeps it floating and opens it on the routed workspace instead of tiling it.
- The permission step asks for Accessibility and nothing else. It lists Stage Manager, macOS edge tiling or another window manager only when one is on, with `Turn off` or `Quit`.
- `Try it` is a miniature desktop to practise on: press `⌥2`, `⌥1`, `⌥⇧Space` and `⌥⇧F`, or click them, to switch workspaces, float a window and fill the screen. Each ticks as you make it, and none of your real windows move while the setup window has the keyboard. `Launch at login` moved here.
- Added `Quit Spaceman` and `Pause & restore windows` to Settings › General, for when the menu bar icon is hidden behind a notch.
- The Workspace HUD is quicker: it appears about 30% faster, and Icons groups, Layouts cells and scrolling settle 20–30% sooner. The marker keeps its stretch.

## Fixes
- The float shortcut no longer tries to float Spaceman's own Settings window.
- `scratchpad mark` on a summoned window tiles it on the workspace showing it, even when its app has a `route` rule to another workspace.
- `move-tab` to a workspace on another display now brings a floating tab to that display instead of leaving it behind.
- A floating window that reopens at a remembered placement now appears on its remembered workspace's display.
- A new window a `route` rule sends to a hidden workspace no longer stays tiled where it opened when hiding it fails; Spaceman tries again on the next pass.
