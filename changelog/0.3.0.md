## Major
### Simpler Workspace HUD
The workspace switch bar now defaults to numbers and app icons in a single calm pill, with a
concentric active marker that springs briskly between workspaces. You can still switch to layout
thumbnails in Settings (`General > HUD style`) or with `hud_style = "layouts"`.
Icon: icons/workspace-hud.svg
## Improvements
- Tighter, snappier HUD spring animations across enter, exit, marker travel, row reflow, and icon emphasis.
- Tabular workspace figures, tighter spacing, and a circular active marker for empty workspaces.
