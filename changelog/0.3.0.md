## Major
### Spaceman is now Pane
Pane is the new name and bundle (`anomaly.pane`) for Spaceman, moving alongside Anomaly's other
Mac apps at anoma.ly/pane. Configuration now lives at `~/.config/pane/config.toml` and state at
`~/Library/Application Support/Pane`; on first launch, existing Spaceman configuration and
recovery state copy over automatically without touching the originals.
Icon: icons/first-preview.svg
### Simpler Workspace HUD
The workspace switch bar now defaults to numbers and app icons in a single calm pill, with a
concentric active marker that springs between workspaces. You can still switch back to layout
thumbnails in Settings (`General > HUD style`) or with `hud_style = "layouts"`.
Icon: icons/workspace-hud.svg
## Improvements
- Tighter spacing, tabular workspace numbers, and a pill-shaped active marker in the Icons HUD.
- Upgrading from Spaceman automatically restores parked windows, swaps in `Pane.app`, and links
  the `pane` CLI alongside `spaceman`.
