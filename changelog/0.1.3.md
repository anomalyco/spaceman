## Improvements
- Remembers window placements across restarts.
- New windows are adopted more reliably, and workspace switches recover from slow apps.
- Focus-follow log lines record recent input timing, without recording which keys were pressed.
## Fixes
- When an app closes its only window by hiding it, the other tiles fill the space within 2 seconds.
- Minimizing an app's only window, or hiding the app with Cmd-H, releases its tile after 2 seconds;
  the window comes back as a new tile.
- A window that refuses a smaller size is treated as constrained, not misplaced.
- Background queries release their memory as they go.
- The bundled TLS libraries no longer trust the compromised eMudhra certificate authorities.
