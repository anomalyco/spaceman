## Fixes
- The setup tour is three steps: Welcome, Accessibility and Done. The confusing starter app rules
  step is gone; set app rules in Settings > Rules whenever you want them.
- Tiling waits until the tour finishes. Granting Accessibility no longer rearranges every window
  behind the setup window; press `Start Tiling` when you are ready.
- Another running window manager is reported in a quiet surface card instead of a bright yellow
  banner.
- macOS 27.3 renamed the Accessibility list to System & App Protection Override and refuses dragged
  tiles. The setup guide now sits outside System Settings with click instructions there, while macOS
  27.0 through 27.2 keeps the drag guide and its Device Control and Data Access name.
