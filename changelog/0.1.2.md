## Major
### Fullscreen Layout
Option+Shift+F fills the screen with the focused window and keeps the split layout, so the same
keys bring it straight back. The menu bar shows a filled workspace glyph while it's on.
Icon: icons/fullscreen-layout.svg
## Improvements
- Option+backtick cycles through tiled windows in workspace order.
- Option+/ leaves Fullscreen Layout and applies the next split at once.
- Fullscreen Layout, focus and layout survive workspace switches, Ghostty tab swaps and restarts.
## Fixes
- Remaining windows expand when another app's temporary window closes.
